# Library System

## Description

Simple Library Information System built with Laravel Framework.

## Requirements

- PHP >= 8.2
- Composer
- MySQL / MariaDB
- Laravel Framework
- Git

## Installation

1. Clone the repository
    ```bash
    git clone [https://github.com/hanny0w0/belajar-laravel.git](https://github.com/hanny0w0/belajar-laravel.git)
    cd belajar-laravel
    ```
